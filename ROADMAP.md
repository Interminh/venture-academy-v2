# Roadmap

Things that should come in future versions:

- [ ] Email reminders to parents and tutors before a session
- [ ] Parents can reschedule a session (not just cancel one)
- [ ] Tutors can set recurring weekly availability
- [ ] Session notes from tutors and students after every session
- [ ] Admin database export for hours and ledger
- [ ] Search and filter on the users, tutors, and tutees page for the admin role

- [ ] Tutor hours summary/dashboard and certificate
- [ ] Waitlist when subjects have no more students needed
- [ ] Translation for the website
- [ ] Different themes and fonts (dark mode, different sizes) for the website
- [ ] Calendar export for booked sessions

- [ ] Add issue and PR templates
- [ ] Public stats on the landing page (hours tutored, students helped)
- [ ] Mobile layout review (already coded for flexibility but thorough review would help)
